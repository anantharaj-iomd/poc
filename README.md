# Shopify MCP Client v2

## Features
- Accepts direct MCP endpoint via `--endpoint` argument (skip discovery if known).
- Supports optional deep discovery with `--deep-discovery` flag.
- Always generates `order_confirmation.json` (mocked if necessary).
- Safe by default: all purchases are **mock** or **test** only.

## Usage Examples
### Using known endpoint
```bash
python client.py --base https://nodenorthstar.com --endpoint https://nodenorthstar.com/.well-known/mcp --output ./out
```

### Auto-discover (basic)
```bash
python client.py --base https://nodenorthstar.com --output ./out
```

### Deep discovery
```bash
python client.py --base https://nodenorthstar.com --deep-discovery --output ./out
```

## Output
- `discovery.json`: Endpoint probing results (only if discovery used).
- `order_confirmation.json`: Always created. Contains MCP or mock confirmation data.
- `products_*.json`: Generated by `mcp_fetch_products.py` and contains MCP/fallback product data.

## Fetching Products via MCP
Call the helper script to invoke an MCP server (with automatic fallback to `/products.json`):
```bash
python mcp_fetch_products.py \
  --base https://nodenorthstar.com \
  --endpoint https://your-store.com/.well-known/mcp \
  --output ./out \
  --limit 25
```
If the MCP server is unavailable, the script saves both the failed MCP payload and the fallback `/products.json` response unless `--skip-fallback` is provided.
